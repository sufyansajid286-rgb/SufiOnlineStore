# Sufi Online Store 🛍️

A modern and responsive e-commerce web application built with React.js and Vite.

## 📌 About the Project

Sufi Online Store is an online shopping website designed to provide users with a smooth and user-friendly shopping experience. Users can explore products, browse categories, manage their cart and wishlist, and place orders.

## ✨ Features

- Responsive Home Page
- Product Listing and Categories
- Product Details
- Shopping Cart
- Wishlist
- User Login and Signup
- User Account Management
- Checkout System
- Order Tracking
- My Orders
- Admin Dashboard
- Product and Order Management
- FAQs and Customer Support Pages
- Shipping Policy
- Returns & Refunds Policy
- Privacy Policy

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- React Router
- Lucide React
- Local Storage

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/sufyansajid286-rgb/SufiOnlineStore.git
   ```

2. Open the project folder:

   ```bash
   cd SufiOnlineStore
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
